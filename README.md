# StudentHub – Student Task & Academic Management System

StudentHub is a full-stack web application designed to help students manage their academic activities, subjects, tasks, and profile information in one place.

## 🌐 Live Demo

Frontend: https://student-hub-nu-gold.vercel.app/

Backend API: https://studenthub-backend-f33t.onrender.com/

## ✨ Features

- 🔐 User Registration & Login
- 🔑 JWT-based Authentication
- 🔒 Password Hashing using bcrypt
- 📊 Student Dashboard
- 📚 Subject Management
- ✅ Task Management
- 📝 Task Status Tracking
- ⚡ Task Priority Management
- 👤 Student Profile Management
- 🚪 Secure Logout
- 🔄 Persistent Login Session
- ☁️ Cloud Database with MongoDB Atlas
- 🚀 Deployed Frontend and Backend
